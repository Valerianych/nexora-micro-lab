# NEXORA — учебный веб-квест

Полный проект: исходники и уже собранный сайт в папке `dist`.
Инструкция по размещению: **HOSTING.md**.

## Быстро разместить сайт

Загрузите **содержимое** папки `dist` в папку сайта на хостинге. Рядом с
`index.html` должны остаться `app.js`, `game.js`, `style.css`, папки `art`,
`avr`, `licenses` и остальные файлы. Серверная база данных и Node.js
для готовой сборки не нужны. Открывайте сайт по HTTP(S), а не двойным
щелчком по `index.html`.

### GitHub Pages

В репозитории уже есть workflow `.github/workflows/pages.yml`. После первого
push откройте **Settings → Pages**, в пункте **Source** выберите
**GitHub Actions**. Следующие обновления ветки `main` будут публиковаться
автоматически.

### Vercel

Конфигурация находится в `vercel.json`. При импорте репозитория Vercel сам
выполнит `npm run build` и опубликует папку `dist`.

## Что реализовано

- Дело 001 «Маяк замолчал»: цепь, переменные, типы данных, условие по кнопке.
- Дело 002 «Сирена сбилась»: осмотр неисправности, измерение импульсов,
  пошаговое объяснение `for`, ремонт и проверка сигнала.
- Дело 003 «Пульт забыл команды»: массив `durations` и индексы.
- Дело 004 «Одинаковые команды»: функции и параметры `blink`.
- Дело 005 «Серверная перегревается»: аналоговый датчик TMP36, `analogRead`
  и порог `>= 35 °C`.
- Дело 006 «Аварийный протокол»: датчик, кнопка, логическое `||`, массив,
  цикл и функция в одной проверяемой программе.
- Комикс со сценами действий, персонажами, уликами и отчётами.
- Редактор Arduino C++, подсказки и диагностика ошибок.
- Локальная компиляция в WebAssembly и выполнение на эмуляторе ATmega328P.
  Провода влияют на результат; проверяется реальный сигнал.
- Автосохранение этапа, навыков, журнала, кода, проводов и температуры датчика
  в текущем браузере; в архиве можно повторить отдельное дело или очистить
  весь прогресс.
- Облегчённые WebP-иллюстрации, предзагрузка соседних сцен, одновременное
  появление готового кадра и текста, повтор загрузки при сетевой ошибке.

## Запуск на компьютере

Если установлен Node.js, откройте терминал в корне проекта:

```sh
npm start
```

Откройте `http://127.0.0.1:8080`. Установка зависимостей для просмотра уже
собранного сайта не требуется. Остановить сервер: `Ctrl+C`.

## Изменение и пересборка

```sh
npm ci
npm run build
```

После пересборки загружайте обновлённую папку `dist` на хостинг.

| Файл | Назначение |
| --- | --- |
| `game.js` | Сюжет, сцены, переходы, архив дел |
| `lessons.js` | Уроки, начальные программы, задания |
| `main.js` | Верстак, провода, редактор, запуск программ |
| `engine.js` | Эмуляция и проверка схемы |
| `case-stories.js` | Сценарии и условия завершения дел 003–006 |
| `case-models.js` | Интерактивные разборы массива, функции, порога и логических связок |
| `case-two.js` | Анализ сигнала и модель цикла |
| `arduino-language.js` | Подсказки и диагностика редактора |
| `progress.js` | Сохранение и восстановление прогресса |
| `story-media.js` | Загрузка изображений и синхронизация сцен |
| `dist/index.html`, `dist/style.css` | Разметка и оформление; редактируются напрямую |
| `dist/art/` | Иллюстрации в трёх размерах |
| `art-direction.json` | Описание сцен для будущей генерации иллюстраций |
| `build.mjs` | Сборка JavaScript и размещение локального компилятора |
| `serve.mjs` | Простой сервер для готовой папки `dist` |

Тесты логики: `npm run check`. Проверка компилятора, схем и учебных программ:
`node verify.mjs` после установки зависимостей и сборки.

Проверка дел 003–006 в настоящем браузере:

```sh
npx playwright install chromium
npm run build
npm run check:browser
```

Тест начинает с сохранения после дела 002. Далее он нажимает кнопки разбора,
соединяет контакты, компилирует исходные и исправленные программы, проверяет
отклонение ошибок, закрытие дел и переходы между ними. Также проверяются
удаление проводов на схеме, контраст текста, сохранение и оба варианта сброса.
В конце проверяются мобильная ширина и удаление с клавиатуры.
`NEXORA_BROWSER_PATH` позволяет указать установленный Chromium;
`NEXORA_TEST_ARTIFACTS` — каталог снимков (по умолчанию `/tmp/nexora-browser-check`).

## Границы текущей версии

Все шесть дел доступны как законченные сюжетные ветки с собственным
обучающим эпизодом и ремонтом на верстаке. ESP32 ещё не реализована;
действующая плата — Arduino Uno.

Внешняя цепь ограничена цифровой моделью: светодиод, резистор, кнопка,
учебный фрагмент макетной платы. Это не универсальный аналоговый симулятор.
Общей базы результатов учащихся и личных кабинетов пока нет.

Сторонние компоненты и уведомления перечислены в `dist/licenses.html`
и `dist/licenses/`. Сохраняйте эти файлы при размещении.
